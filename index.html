Para o seu chatbot responder com IA real, você pode usar a Gemini API gratuitamente pelo Google AI Studio.

Como conseguir sua chave grátis:

  2. Faça login com sua conta Google.
  3. Clique em "Create API key" e copie a chave gerada.
